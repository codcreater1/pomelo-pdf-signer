PDF Signer Project


Project Leader: Murat Can Nergiz

This tool allows users to upload a PDF document, specify a signature location via a web interface, and apply a signature from an image file.

👥 Team & Responsibilities
1 & 2. Back-end, PDF Processing & API Management
Leads: Murat Can Nergiz & Arda Turgut

Establish PDF manipulation infrastructure using Python libraries such as PyMuPDF or ReportLab.

Develop the algorithm to embed the signature image at specific (X, Y) coordinates within the PDF.

Create API endpoints (Upload, Process, Download) using FastAPI or Flask.

Manage file upload processes, temporary storage, and ensure robust error handling.

Implement the final function to generate and export the signed PDF.

3. Front-end Developer (UI/UX)
Lead: Faik Arda Hüseyinoğlu

Design user-friendly upload zones (drag & drop) for PDF and signature files.

Implement a browser-based preview for the uploaded PDF.

Develop the overall page layout and interactive UI components.

4. Front-end Interactivity & Integration
Lead: Eylül Kılagöz

Build the mechanism to capture the specific coordinates where the user clicks to place the signature.

Establish the connection between the Front-end and Back-end API using Fetch or Axios.

Coordinate system testing and maintain the project documentation.

🛠 Tech Stack
Language: Python

Back-end: FastAPI / Flask

Front-end: React / Vue.js

Libraries: PyMuPDF, ReportLab
